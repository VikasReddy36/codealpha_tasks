# CodeAlpha Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

## 📌 Features

- Displays available stocks and their prices
- Allows the user to enter stock symbols
- Allows the user to enter quantities
- Calculates the value of each stock
- Calculates the total investment value
- Handles invalid stock symbols and quantities

## 🛠️ Technologies Used

- Python
- Dictionary
- Functions
- Loops
- Conditional statements
- User input
- Basic arithmetic

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python stock_portfolio.py
