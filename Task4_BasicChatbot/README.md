# CodeAlpha Basic Chatbot

A simple rule-based chatbot developed in Python as part of the CodeAlpha Python Programming Internship.

## 💬 Features

- Responds to greetings
- Answers simple questions
- Provides predefined responses
- Continues chatting until the user types `bye`
- Uses functions and conditional statements

## 🛠️ Technologies Used

- Python
- Functions
- if-elif statements
- While loop
- User input and output

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python chatbot.py
