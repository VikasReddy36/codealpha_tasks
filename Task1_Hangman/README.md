# CodeAlpha Hangman Game

A simple text-based Hangman game developed in Python as part of the CodeAlpha Python Programming Internship.

## 🎮 How the Game Works

The computer randomly selects a word from a predefined list of 5 words.

The player guesses the word one letter at a time.

- You can guess one letter at a time.
- Correct guesses reveal the letter.
- Incorrect guesses are counted.
- The player gets a maximum of 6 incorrect guesses.
- The game ends when the word is guessed or all 6 incorrect guesses are used.

## 🛠️ Technologies Used

- Python
- Random module
- While loops
- If-else statements
- Strings
- Lists
